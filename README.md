## Main Project

### 売上集計自動化ツール

複数モールの売上集計業務を自動化するために開発したツールです。

対応モール

* 楽天市場
* Yahoo!ショッピング
* au PAY マーケット
* Amazon
* Qoo10
* dショッピング

#### Background

月次売上集計では、

* CSV取得
* Excel転記
* オートフィル
* 親品番集計
* SKU集計

などを手作業で行っており、多くの工数が発生していました。

#### Solution

Pythonを利用して、

* CSV読込
* Excel転記
* 集計処理
* ログ出力
* GUI操作

を自動化しました。

#### Design Decisions

売上データを扱うため、完全自動化は採用していません。

重視した点

* サイレントエラーを防ぐ
* 成功・失敗を問わずログを残す
* 最終確認は人間が行う
* CSV取り違えを防止する
* 非エンジニアでも利用できるGUI
* モール追加に対応しやすいYAML設定

#### Result

月40時間規模の作業削減を見込んでいます。

## Development Philosophy

私が重視しているのは「完全自動化」ではなく「安全に運用できる自動化」です。

業務改善では、

* 確認しやすいこと
* トラブル時に原因を追えること
* 担当者が変わっても運用できること

を優先しています。

そのため、

* ログを残す
* エラーを見える化する
* 人による最終確認を残す
* 運用負荷を減らす

といった設計を心掛けています。
